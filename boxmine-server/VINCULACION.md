Boxmine como Proxy/API Gateway (RECOMENDADO)\n\n### Paso 1: Registrar tu servidor en Boxmine\n\n```bash\n# En el dashboard de Boxmine:\n# Settings → Integrations → Custom Server\n\n# Datos:\n- Server URL: http://tu-dominio.com:5000\n- API Token: tu_token_secreto_aqui\n- Environment: development (o production)\n```\n\n### Paso 2: Actualizar configuración del bot\n\nEn `.env` del bot principal:\n\n```env\n# Apuntar al servidor personalizado como Boxmine\nBOXMINE_URL=http://localhost:5000\nBOXMINE_TOKEN=tu_token_secreto_aqui\nBOXMINE_API_KEY=ignorar_si_usas_token\n```\n\n### Paso 3: Verificar conexión\n\n```bash\ncd boxmine-server\nnpm start\n\n# En otra terminal, hacer test:\ncurl -H \"Authorization: Bearer tu_token_secreto_aqui\" \\\n     http://localhost:5000/health\n\n# Debe retornar:\n# {\"success\": true, \"status\": \"operational\"}\n```\n\n---\n\n## ✅ OPCIÓN 2: Sincronización Bidireccional (Híbrido)\n\nSi tienes cuenta en Boxmine.io y quieres sincronizar datos entre ambos:\n\n### Paso 1: Obtener credenciales de Boxmine.io\n\n```bash\n# En https://app.boxmine.io\n# Settings → API Keys → Copiar:\n- API_KEY\n- TOKEN\n```\n\n### Paso 2: Configurar en servidor personalizado\n\nEdita `boxmine-server/.env`:\n\n```env\nNODE_ENV=development\nBOXMINE_PORT=5000\nBOXMINE_TOKEN=tu_token_secreto_local\n\n# Conexión con Boxmine.io (Independiente)\n\nSi quieres que tu servidor sea **completamente independiente** pero reciba eventos de Boxmine.io:\n\n### Paso 1: Crear endpoint para webhooks\n\nEn `boxmine-server/index.js` (ya existe):\n\n```javascript\n// POST /webhook/receive\napp.post('/webhook/receive', express.json(), (req, res) => {\n  const { event, data } = req.body;\n  \n  console.log(`📨 Evento recibido de Boxmine.io: ${event}`);\n  \n  // Procesar evento\n  handleBoxmineEvent(event, data);\n  \n  res.json({ success: true, message: 'Webhook procesado' });\n});\n```\n\n### Paso 2: Registrar webhook en Boxmine.io\n\n```bash\n# En https://app.boxmine.io\n# Settings → Webhooks → Add Webhook\n\nURL: http://tu-dominio.com:5000/webhook/receive\nEvents: \n  - user.created\n  - message.received\n  - campaign.completed\n```\n\n---\n\n## 🎯 RECOMENDACIÓN FINAL\n\n### **Flujo Recomendado:**\n\n```\n┌─────────────────┐\n│  WhatsApp Bot   │ (index.js)\n└────────┬────────┘\n         │\n         │
